## How to Add a Real Asset

1. Create the file at the path listed above.
2. Open the Godot editor once to trigger automatic import (or run
   `godot --headless --import` in CI).
3. Restart the game — `AssetRegistry` picks it up automatically.
4. No code changes required.

For music `.ogg` files, set the **Loop** flag in Godot's import panel and set
**Loop Offset** to the beat boundary specified in the spec column.

## Regenerating Placeholder Audio

```bash
python3 tools/gen_audio.py
```

Regenerates all `.wav` stubs listed above (both music click tracks and SFX).
Zone 5's variable-BPM track is derived from `assets/levels/z5_tempo_curve.json`
— edit that file and re-run to keep audio and beat_map in sync.
